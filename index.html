 UN EXPLORATEUR, PAS LE CLIENT DU JEU

Ce que vous voyez.

Positions lues sur le serveur pour votre royaume 690. Il s’agit d’un instantané séquentiel, pas d’un suivi en temps réel ; seuls les objets visibles dans les réponses sont connus.

Couverture : les 400 zones sont lues au LOD 1 pour les châteaux, drapeaux, QG et gisements. Une lecture LOD 0 des petites zones autour des QG repère les pièges à ours et les autres bâtiments d’alliance. Ces derniers peuvent être absents s’ils sont éloignés des QG : ce n’est pas un inventaire exhaustif.

Terrain / TP : le masque original est identique au fichier récupéré avec REA dans le cache de l’émulateur. Le calque identifie les exclusions statiques et le contrôleur examine toute l’empreinte 2×2 d’un château. Une absence d’exclusion n’est pas une autorisation : occupation, terrain complémentaire, brouillard, conditions du joueur/alliance/guerre et validation serveur restent inconnus. Aucun TP n’est envoyé.

Vue Plan : rectangles orthogonaux aux dimensions de la configuration du jeu, sans taille artificielle de sprite. X,Y indiquent le coin de coordonnées minimales ; un château2×2 à X676/Y402 couvre X676–677 et Y402–403. Les plages apparaissent dans la fiche et les cellules de l’objet sélectionné au zoom rapproché. Les zones de territoire/protection ne sont pas son empreinte. Une taille inconnue reste signalée comme telle. L’instantané n’établit ni l’occupation actuelle complète ni une autorisation de placement.

Ressources : les gisements d’alliance (type 35) produisent des ressources pour l’alliance. Les mines sécurisées (type 39) sont des centres de récolte construits par l’alliance. Ce sont deux catégories distinctes. Les ressources classiques (type 2) ne sont pas exportées actuellement.

Envahisseurs : l’onglet montre seulement les joueurs dont le royaume d’origine connu diffère de 690. Leur origine ne prouve pas leur hostilité ; une origine inconnue est exclue, jamais devinée. Les résultats décrivent l’instantané, pas la présence actuelle.

Limites rouges : contours extérieurs des zones 8/9 du masque original, affichés sur les deux fonds. La couleur est explicative, pas un shader natif récupéré. Le masque 9 est interdit statiquement ; le masque 8 correspond aux zones spéciales des sites et n’est pas globalement interdit aux TP. Les états de territoire et de protection ne sont pas connus.

Logos des sites fixes : sept logos de mini-carte sont extraits du cache du jeu : château central, quatre sanctuaires, fort moyen et tour. Leurs pixels sources sont connus ; le format de texture et les offsets de deux logos sont inférés, comme indiqué dans la provenance. Le logo du grand fort reste non récupéré et n’est pas remplacé par un autre bâtiment. Ce ne sont pas les modèles 3D natifs.

Autres bâtiments : Arsenal, Mobilisation, Confrontation et mines sécurisées utilisent 13 logos originaux d’interface récupérés dans le cache (format ASTC inféré, pixels sources connus). Les variantes suivent le niveau ou la ressource lorsque ces données sont connues. Le niveau manque dans l’instantané actuel des bâtiments d’honneur : un logo de base est affiché avec une notice. Les banquets et tables restent sans visuel original récupéré.

Le fond reconstruit utilise la géographie du masque 1200 × 1200 et des couleurs mesurées dans vos captures du jeu : herbe, eau et berges. Il ne s’agit pas d’une texture native récupérée. Le relief reste illustratif, et les positions originales des arbres/rochers ne sont pas établies.

Les quatre gisements utilisent maintenant leurs visuels du jeu (moulin/ferme, scierie, carrière, fonderie), dans la carte, les résultats et les fiches. Leurs pixels sources sont vérifiés ; quelques champs de métadonnées reconstruits sont documentés dans la provenance. Les drapeaux, pièges à ours et certains châteaux utilisent aussi les sprites récupérés. Les skins manquants restent illustratifs ; l’affectation du sprite QG est inférée.

Couleurs : les identifiants natifs flag / flag_bg sont conservés. Les fonds natifs n’étant pas récupérés, les couleurs affichées sont une palette locale par alliance, modifiable dans une fiche. Elles ne prétendent pas reproduire la couleur exacte du jeu.

Tous les bâtiments reçus sont conservés, y compris les gisements sans propriétaire. Les abréviations connues sont partagées entre les objets de la même alliance via son identifiant et précèdent le nom du joueur. Le nom complet de l’alliance n’est pas récupéré.

Le site reste local : accès Wi-Fi en lecture seule lorsqu’il est activé, actualisation réservée au Mac via127.0.0.1. Aucune publication ni outil d’analyse externe. Les fichiers d’authentification ne sont jamais servis.
